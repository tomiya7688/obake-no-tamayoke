# おばけの弾除け — 仕様書

> この文書は、制作者が会話で明示した『おばけの弾除け』の仕様をまとめたものです。
> 決まっていない事項を推測で確定させないため、末尾に「未決定事項」を分けて記載しています。

## 1. ゲーム概要

| 項目 | 内容 |
| --- | --- |
| タイトル | おばけの弾除け |
| ジャンル | 弾幕回避ゲーム |
| 開発 | Python + Pygame |
| 実行ファイル化 | PyInstaller |
| 自機 | まる、または、かどか |
| 基本的な遊び | おばけを操作して、飛んでくる弾を避ける |

**おばけは弾を撃てない。** 敵を攻撃して倒すゲームではなく、弾を避けることが中心。

## 2. 敵と弾幕

- 自機から弾を撃つことはできない。
- 敵を倒すこともできない。
- 敵はいつか**飽きてどこかへ行く**。倒されたり、撃破演出で退場したりするわけではない。
- 敵が帰るまでの時間、弾幕の種類、敵の数、退場後の進行方法は現時点では未決定。

## 3. 難易度とExtraステージ

本編の難易度は、某弾幕ゲームを彷彿とさせる次の **4段階**。

1. `easy`
2. `normal`
3. `hard`
4. `lunatic`

### `lunatic` の難易度方針

- **文字どおり「lunatic」と呼べる、非常に高難度の弾幕**にする。
- 某弾幕ゲームやアーケードインベーダー並みの難しさをイメージし、**それ以上に難しくしてもよい**。
- 本作の自機は弾を撃てず、プレイヤーがすることは基本的に**弾を避けることだけ**。攻撃操作や敵の撃破を考える必要がないため、その分、回避自体に強い難しさを持たせる。
- 弾の密度・速度・軌道・隙間の狭さなど、難度を生む具体的な設計値は未決定。「必ず他作品より難しい」などの定量的な比較は現時点では確定していない。

### 難易度の制作順（開発方針案）

**最初に `lunatic` の弾幕を作り、そこを基準に `hard` → `normal` → `easy` の順で難易度を下げていく。**

- まず最上位難易度の弾幕パターンを設計する。
- 下位難易度は、弾の数・速度・発射間隔・攻撃パターンなどを調整して作る。調整項目と具体的な数値は未決定。
- 単純に弾を間引くだけでなく、下位難易度でも避け方が分かりやすい配置にすることを検討する。
- これは**制作順序の方針案**であり、プレイヤーが難易度を選べる順番や `extra` の解放条件を変更するものではない。

**`lunatic` をクリアすると、`extra` ステージが解放される。**

- `extra` は本編の5つ目の難易度ではなく、クリア後に解放される追加ステージ。
- 各難易度の具体的な弾幕・敵の挙動の差、クリア判定の詳細、`extra` ステージの内容や解放状態の保存方法などは未決定。

## 4. 拾えるカード

### スコアカード

- 拾うとスコアがもらえる。
- **嬉しいだけ。** 攻撃や防御の強化アイテムではない。
- 何点増えるか、出現頻度などの数値は未決定。

### すり抜けカード

- 拾うと「すり抜け」を入手する。
- **3秒間、弾に対して無敵**になる。
- 効果中は自機に触れた弾が、当たらずにそのまま通過する。
- 効果の重複・再取得時の残り時間の扱い、表示演出などは未決定。

## 5. ゲームオーバー

ゲームオーバー画面は、**現在の自機のアップ画像と吹き出し**で構成する。吹き出しの文言は次のとおり。

| 自機 | 吹き出しのセリフ（表記どおり） |
| --- | --- |
| まる | `痛いのだ...` |
| かどか | `いたい...` |

- おばけは世界設定上、死なない。ゲームオーバーを「死亡」として描かない。
- 上記以外の大がかりなゲームオーバー演出は、現時点では仕様に含めない。
- 何回の被弾でゲームオーバーになるか、リトライ操作などは未決定。

## 6. キャラクターと世界観

自機に使うおばけは、**まる**と**かどか**。独自キャラクターとして描き直して設定を変更するのではなく、公式素材と正式なキャラクター設定を参照する。

### まる

- 白く丸い、小さなおばけ。手・腕がなく、普段はふよふよ浮く。
- 理解力や判断力は人間より低く、思いつきで動きがち。
- 一人称は「まる」。語尾に「なのだ！」をよく使う。
- ゲームオーバー時は **「痛いのだ...」** と言う。

### かどか

- まるより輪郭がはっきりしており、身体の左右に小さな手がある。普段はふよふよ浮く。
- まるより少し賢いが、人間並みの常識人ではない。口数が少ない。
- 一人称は「僕」。短く静かに話す。
- ゲームオーバー時は **「いたい...」** と言う。

### 2匹に共通する設定と、ゲームの扱い

- 2匹ともおばけであり、死という概念は適用されない。ただし痛がることはある。
- 力は弱いが、その気になればかなり速く移動できる。
- 公式世界設定上は、壁や岩などの物体を時間制限なしですり抜けられる。ただし2匹は、その能力をうまく使いこなせない。
- **ゲーム内の「すり抜けカード」は、弾に対する3秒間の無敵というゲームルール。** 世界設定の恒常的なすり抜け能力を上書きする設定ではない。
- おばけの住処の常住者はまるとかどかの2匹だけ。ゲームに敵が出ることを理由に、敵を住処の住人として設定に追加しない。

## 8. 実装時に守ること

- Pygameを使い、PyInstallerで実行ファイル化できるようにする。
- 自機に射撃・敵撃破の仕組みを追加しない。
- 本編の難易度は `easy` / `normal` / `hard` / `lunatic` の4段階とし、`lunatic` クリア後に `extra` ステージを解放する。
- スコアカードに点数獲得以外の便利な効果を勝手につけない。
- すり抜けカードの有効時間は **3秒** とし、弾はおばけを通過する。
- ゲームオーバーの吹き出しは、自機ごとに指定された文言を正確に使う。
- おばけの公式素材・世界設定を優先し、新しい設定を勝手に公式化しない。
